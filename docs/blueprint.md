# **App Name**: The Grid

## Core Features:

- Citizen Report Submission: Allow citizens to submit reports with type, description, location (GeoPoint), media, and timestamp.
- Admin Dashboard: Provide an interface for admins to view, assign, and update the status of reports.
- Geofencing/Routing: Automatically assign an admin/zone to a new report based on its location. The location is used as a tool by the AI.
- Status Tracking: Automatically check if a report's resolution deadline has been missed and trigger overdue alerts.
- User Authentication: Implement secure login and signup for both citizens and admins.
- Real-Time Notifications: Send real-time notifications to admins about new reports in their zone, and to citizens when their report status changes.
- Multi-Language Support: Support localization for English and Hindi.

## Style Guidelines:

- Primary color: Deep blue (#3F51B5) for trust and authority, inspired by the seriousness of the app's purpose.
- Background color: Light blue (#E3F2FD), desaturated to 20% for a calm and reliable feel.
- Accent color: Purple (#7E57C2) for highlights and calls to action.
- Body and headline font: 'Inter' for a modern, neutral, and readable design.
- Use clear and recognizable icons to represent different report types.
- Design a clear layout that separates the citizen app from the admin dashboard.
- Use subtle animations to indicate status updates and guide user interactions.
